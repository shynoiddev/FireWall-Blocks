FireWall Blocks is a simple, open-source Android firewall that blocks app internet access using either Shizuku or a local VPN, with no root requirement.

Features:

* Dual Mode: Choose between the efficient Shizuku mode (recommended) or the no-setup-required VPN mode. You can even use them at the same time!
* Network Monitoring Screen: Real-time traffic tracking via local VPN. See which apps are actively trying to access the network and block or allow connections directly from the live monitoring log.
* Per-App Rules: Control Wi-Fi and Mobile Data access for each app individually.
* Import/Export: Save and load your firewall rules as a simple .json file.
* Sorting: Advanced filtering based on user apps, system apps, network permission, disabled status, uninstalled leftover rules, or blocked-placement priority.
* Efficient: The app doesn't need to be constantly running in the background when utilizing Shizuku mode.
* Elegant Reapplying: Hassle-free user experience on startup.
* App search and more

How to Use:

1. Enable the Firewall: Press the "Enable" button on the main screen.
2. Choose Mode: Toggle between "Shizuku" (requires setup) or "VPN" (works instantly).
3. Block Apps: Tap the Wi-Fi or Data icons next to any app to block its access.
4. Network Monitoring: Access "Network monitoring" from the top-right menu to see app connection requests in real-time.

Note: After rebooting your phone, for Shizuku mode, you must first start Shizuku, then re-open the app to re-apply the rules.
